# Mandatory Remotion Coding Rules (CRITICAL for Executable Video Code)
When writing or editing Remotion React code in `apps/src/remotion/NexusVideoComposition.tsx`:
1. **Frame-Driven Animations ONLY (No CSS Transitions / No `setTimeout`):**
   - Remotion renders frames in parallel headless browser tabs. NEVER use CSS `transition`, CSS `@keyframes`, `setTimeout`, `setInterval`, or `requestAnimationFrame` for video animations — they will fail during MP4 rendering.
   - ALWAYS drive every animation mathematically from `const frame = useCurrentFrame()` and `const { fps, durationInFrames, width, height } = useVideoConfig()` using `spring()` and `interpolate()` from `"remotion"`:
   ```tsx
   import { AbsoluteFill, Sequence, interpolate, spring, useCurrentFrame, useVideoConfig } from "remotion";

   const MyAnimatedLayer: React.FC<{ text: string }> = ({ text }) => {
     const frame = useCurrentFrame(); // Relative to parent <Sequence from={...}>!
     const { fps } = useVideoConfig();
     const progress = spring({ frame, fps, config: { damping: 14, stiffness: 120 } });
     const opacity = interpolate(frame, [0, 12], [0, 1], { extrapolateLeft: "clamp", extrapolateRight: "clamp" });
     const translateY = interpolate(progress, [0, 1], [30, 0]);

     return (
       <div style={{ opacity, transform: `translateY(${translateY}px)` }}>
         {text}
       </div>
     );
   };
   ```
2. **Remember `useCurrentFrame()` Inside `<Sequence>` Starts at `0`:**
   - Any child component rendered inside `<Sequence from={startFrame} durationInFrames={dur}>` receives `useCurrentFrame()` starting at `0` when the global playhead reaches `startFrame`.
   - Always use `layout="none"` on `<Sequence>` when placing a sequence inside a Flexbox or CSS Grid container so Remotion does not wrap it in an extra `position: absolute` div.
3. **Multi-Layer `<Sequence>` Decomposition (`V1`..`Vn`):**
   - Decompose every visual element into its own `<Sequence>` wired to `buildCompositionLayers(props, durationInFrames)`:
     - Background base gradient (`bg-base`)
     - Background pattern/particle overlays (`bg-orb-pattern`, `bg-grid-pattern`)
     - Top HUD badges/labels (`hud-category`, `hud-subcategory`)
     - Main hook headline (`text-hook`)
     - Individual content/bullet cards (`text-bullet-0`, `text-bullet-1`, ..., `text-bullet-N`)
     - Custom visual layers (`customLayers`: charts, counters, callout badges, SVG graphics, media overlays)
     - Footer branding layers (`footer-icon`, `footer-author`, `footer-tag`)
4. **Static Assets (`staticFile`):**
   - Local images, audio, and videos placed in `public/` (or `apps/public/`) must be referenced via `staticFile("filename.png")` imported from `"remotion"`, paired with `<Img>`, `<Audio>`, or `<OffthreadVideo>` from `"remotion"`.
