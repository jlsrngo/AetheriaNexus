# Aetheria Modular HTML Motion Engine Guidelines (`index.html` + `script/scene1..N.js`)
We use a deterministic **Modular HTML Motion Engine** (supporting HTML5 2D Canvas, SVG, and 3D WebGL / Three.js depending on the active `/skill`) instead of React/Remotion `.tsx` components AND instead of cramming 1,000+ lines into a single monolithic HTML file.

1. **Why Per-Scene Modular Scripts (`script/scene1.js` .. `sceneN.js`) Are Mandatory**:
   - NEVER cram all scenes of a multi-scene video into a single giant `index.html` file. Writing 1,000+ lines in one file hits LLM output token limits and degrades animation quality on later scenes.
   - Instead, write **one modular script per scene** in `script/scene1.js`, `script/scene2.js`, ..., `script/sceneN.js` (~120–180 lines each).
   - Each `script/sceneK.js` registers its renderer via `AM.registerScene`:
     ```js
     (function () {
       var AM = window.AM;
       AM.registerScene("scene1_hook", function (ctx, localTime, dur, scene, AM) {
         // 3-4 sequential visual beats using localTime, dur, scene.accent, AM.spring, AM.ease, etc.
       });
     })();
     ```
   - `AM.getSceneRenderer(scene.id, resolved.index)` automatically resolves by exact `scene.id` (e.g. `"scene1_hook"`), 1-based `"scene1"`, or 0-based `index` (`0`), and runs inside `try / catch` so a typo in one scene never crashes the entire video player.

2. **Lightweight Stage Orchestrator Contract (`index.html`)**:
   - Load `/script/aetheria-motion.js` and `/script/scene1.js` .. `/script/sceneN.js` in `<head>`:
     ```html
     <script src="/script/aetheria-motion.js"></script>
     <script src="/script/scene1.js"></script>
     <script src="/script/scene2.js"></script>
     ```
   - Declare `SCENES` and `window.__filmMeta = { title, width: 1080, height: 1920, fps: 30, duration, durationInFrames, scenes: SCENES }`.
   - Preload all `/audio/*.words.json` files via `fetch()`, set `window.__ready = true`, and call `window.renderAt(0)` once ready. NEVER cover the canvas with a `#loading` splash curtain or add standalone `#controls` Play/timeline overlay UI — Aetheria Studio provides its own interactive Timeline and audio sync player cleanly around the canvas.
   - Define `window.renderAt = function(t) { ... }` where `t` is the global playback time in seconds (`frame / fps`):
     - Resolve the active scene with `var resolved = AM.resolveScene(currentTime, SCENES);`.
     - Dispatch the per-scene renderer: `var renderFn = AM.getSceneRenderer(scene.id, resolved.index); if (renderFn) renderFn(ctx, resolved.localTime, scene.duration, scene, AM);`.
     - HUD & Subtitles (Governed by Active `/skill`): `AM.drawTopHeader(...)` and `AM.drawHeadlinePlaque(...)` are **OPTIONAL** editorial helpers — do NOT draw them unless the active skill's `SKILL.md` or user asks for header/plaque chrome. Always style `AM.drawSubtitles(ctx, words, localTime, opts)` (or custom caption rendering) using the active skill's `tokens.json` / `SKILL.md` rules instead of generic dark defaults.

3. **Using the `window.AM` Runtime (`/script/aetheria-motion.js`)**:
   - **Math & Interpolation**: `AM.clamp(v, min, max)`, `AM.lerp(a, b, t)`, `AM.invLerp(a, b, v)` (or `AM.inv(a, b, v)`), `AM.remap(v, inMin, inMax, outMin, outMax, easeFn)`, `AM.smoothstep(e0, e1, x)`, `AM.hump(u)`, `AM.crisp(t, k)`, `AM.arcP(P0, P1, H, q)`, `AM.mixHex(a, b, k)`.
   - **Deterministic Seeded PRNG & Noise (NEVER use `Math.random()`)**: `AM.rand(seed)`, `AM.rng(seed)`, `AM.noise1D(x, seed)`, `AM.noise2D(x, y, seed)`.
   - **Velocity-Driven Easing & Spring Physics Helpers**:
     - `AM.bezier(x1, y1, x2, y2)`, `AM.E` (`inQ`, `outQ`, `ioQ`, `inC`, `outC`, `ioC`, `outQt`, `ioQt`, `outX`, `outB`, `inB`, `pop`), `AM.ease`.
     - `AM.spring(t, f, z)` (closed-form frequency `f` in Hz & damping `z`) and `AM.springV(t, f, z)` (closed-form spring velocity).
     - `AM.pop(t, t0, f, z, amt, pin)` — returns `[s, k]` (spring scale `s` + velocity-driven squash/stretch factor `k`, pinned to `[1, 0]` after `pin` seconds so there is zero sub-pixel drift under camera zoom!). Apply as `scaleX = s / (1 + k)`, `scaleY = s * (1 + k)`.
     - `AM.kick(t, t0, f, z)` — damped impulse wave (`0 -> peak -> 0`) for camera impact shake, head nod, hair bounce, and landing thuds.
     - `AM.anticipation(p, dip)`, `AM.stagger(t, index, start, stepDelay, duration, easeFn)`, `AM.squashStretch(velocity, amount)`.
   - **SVG Scene-Graph & Accent Primitives**: `AM.el(tag, attrs, parent)`, `AM.G(parent, attrs)`, `AM.tf(node, x, y, sx, sy, r)`, `AM.vis(node, visible)`, `AM.burstLine(ln, cx, cy, a, r0, r1, t, t0, dur)`, `AM.ring(c, t, t0, r0, r1, w0, dur)`.
   - **Canvas 2D Drawing, Camera & Rigging Helpers**: `AM.roundRect(ctx, x, y, w, h, r)`, `AM.hexAlpha(hex, alpha)`, `AM.applyCamera(ctx, cam, W, H)`, `AM.drawShapeWipe(ctx, t, tStart, dur, colors, originX, originY)`, `AM.drawCharacterRig(ctx, t, opts)`, `AM.drawBurstLines(ctx, cx, cy, count, r0, r1, t, t0, dur, color, width)`, `AM.drawShockRing(ctx, cx, cy, t, t0, r0, r1, w0, dur, color)`, `AM.drawGridBackdrop(ctx, t, accentHex, bgTop, bgBottom)`, `AM.drawElectricBolt(ctx, x1, y1, x2, y2, segments, spread, seed, color, width)`, `AM.drawTopHeader(ctx, scene, localTime, globalTime)`, `AM.drawHeadlinePlaque(ctx, scene, localTime)`, `AM.drawSubtitles(ctx, words, localTime, accentHex)`.
