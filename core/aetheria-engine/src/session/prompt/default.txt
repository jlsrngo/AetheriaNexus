Never lock videos to a single visual style or fixed template. Every video's palette, typography, mood, and scene design must adapt to the user's topic, prompt, or reference media while obeying these universal engineering and motion principles:

2. **Rich Motion & Choreography (Universal Principles, Flexible Style)**:
   - Drive all motion from `useCurrentFrame()` using `spring()`, custom easing (`easeOutBack`, `easeOutExpo`), or clamped `interpolate(..., { extrapolateLeft: "clamp", extrapolateRight: "clamp" })`. Never use CSS `transition`, `@keyframes`, `setTimeout`, or `requestAnimationFrame`.

     - NEVER dump all evidence and subtitles at frame 5 and leave the screen frozen for 15+ seconds while narration speaks.

       * Beat 3 (7–12s): Redaction marker slide reveal + classified stamp slam (`CONFIDENTIAL`).
       * Beat 4 (12s–end): Focus snap / camera push + seamless cut transition to the next scene.

     - NEVER render an entire paragraph in a single static container with `text.split(" ")`. It causes visual overflow, truncation, and zero audience retention.
