# render_video

Triggers the local Nexus rendering pipeline to export the active video composition to an MP4 file on disk.

This tool is the programmatic equivalent of clicking the "[↓] RENDER MP4" button on the desktop UI.

### When to use:
- Use when the user explicitly requests to render, export, or generate the physical MP4 video file (especially when communicating via automated triggers or remote bots like Telegram).
- Do NOT use this tool to write or edit video scripts or change visual colors. To edit scripts or modify layout props, discuss with the user and edit the composition files using standard `write_file` or `edit_file`.

### Parameters:
- `composition_id` (string, optional): The Nexus composition identifier to render (default: "NexusEditorialVideo"; unknown ids fall back to the first registered composition).
- `output_path` (string, optional): Target MP4 file path, resolved against the active project folder (e.g. "export/wealth-habits.mp4").

### Example:
```json
{
  "output_path": "export/wealth-habits.mp4"
}
```
