# render_video

Triggers the native pure-Rust Chrome/Edge CDP + FFmpeg exporter to render the active project's `index.html` + `script/*.js` + `audio/*` into an MP4 file on disk.

This tool is the programmatic equivalent of clicking the Export MP4 button on the desktop Studio timeline.

### When to use:
- Use when the user explicitly requests to render, export, or generate the physical MP4 video file.
- Do NOT use this tool to write or edit HTML/JS scene scripts. Edit `index.html` and `script/scene*.js` directly with `write` or `edit`.

### Parameters:
- `composition_id` (string, optional): Optional label for the render job (defaults to `"HtmlMotionFilm"`).
- `output_path` (string, optional): Target MP4 file path, resolved against the active project folder (e.g. `"output/my-video.mp4"`).
- `codec` (string, optional): Video codec (`"h264"`, `"h265"`, `"vp9"`, `"prores"`). Defaults to `"h264"`.

### Example:
```json
{
  "output_path": "output/wealth-habits.mp4"
}
```
